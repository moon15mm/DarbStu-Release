# تطبيق درب للأندرويد

تطبيق واحد يتصل بأي مدرسة على نظام درب. يعرض لوحة الويب نفسها
(`/web/dashboard`) بحسابات المدرسة وصلاحياتها، فكل ميزة جديدة في النظام
تظهر في التطبيق تلقائياً دون إصدار جديد.

## الربط بمدرسة
- «إضافة مدرسة» ← اكتب رمز المدرسة (مثل `alnoor`) أو رابطها الكامل.
- يتحقق التطبيق من `https://<الرمز>.darbstu.com/health` ثم يحفظها.
- يمكن حفظ عدة مدارس والتبديل بينها، وتسجيل الدخول محفوظ لكل مدرسة.
- رابط ربط سريع (يصلح في رمز QR): `darbstu://connect?school=alnoor`

## ما يدعمه داخل التطبيق
- تسجيل الدخول والجلسة الدائمة.
- الطباعة (`window.print`) عبر خدمة الطباعة في أندرويد، ومنها الحفظ PDF.
- تنزيل التقارير وملفات Excel/PDF (ومنها ملفات `blob:`) إلى «التنزيلات/Darb».
- رفع الملفات (استيراد الطلاب، المرفقات).
- روابط واتساب والهاتف تُفتح في تطبيقاتها.
- شاشة «لا يوجد اتصال» عند إطفاء جهاز المدرسة أو انقطاع النفق.

## البناء
تلقائياً: كل دفع يمسّ `android_app/` يشغّل GitHub Actions
(`.github/workflows/android-apk.yml`)، والـ APK يظهر في **Artifacts**
باسم `DarbStu-apk`. ويمكن تشغيله يدوياً من تبويب Actions مع رقم إصدار.

محلياً (يتطلب Android SDK):

```bash
cd android_app && ./gradlew assembleRelease
```

### التوقيع الدائم (مهم قبل التوزيع)
بدون مفتاح يُوقَّع APK بمفتاح التصحيح، ولن تُثبَّت التحديثات فوقه إن تغيّر
المفتاح. أنشئ مفتاحاً مرة واحدة:

```bash
keytool -genkey -v -keystore darbstu.jks -keyalg RSA -keysize 2048 -validity 10000 -alias darbstu
```

ثم أضف في أسرار المستودع: `ANDROID_KEYSTORE_BASE64` (ناتج `base64 -w0 darbstu.jks`)،
`ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS`، `ANDROID_KEY_PASSWORD`.
